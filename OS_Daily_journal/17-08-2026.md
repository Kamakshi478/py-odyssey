# Operating system 
## Introduction
  - The core software that manages a computers hardware and provides a platform for application to run.
## Core functions of an OS 
  - Process management : Handles program creation, execution and CPU scheduling.
  - memory management : Allocates and track main memory (RAM) for active tasks.
  - File system : Organizes, retrieves and protects data stored on drives .
  - Device control : Communicates with hardware via drives and device controllers .

## How it Works ?
  - So an operating system works by acting as an invisible manager that constantly translates software requests into hardware action.
  - It controls the flow of data between applications and the physical components of the computer using a continuous cycle of resource allocation, task switching and security check.

### The Startup Phase (Booting)
  - Power on : The computer activate its firmware known as BIOS or UEFI.
  - Hardware check: The firmware performs a power-on-self test (POST). To ensure components like RAM And storage are working .
  - loading the kernel : The firmware hands control over a small program called the bootloader, which pulls the OS kernel from your drive and loads it into the computers RAM .
  - User interface initialisation : The kernel starts system services and launches the Graphical user interface (GUI) or command line for  you to log in
  
### Running applications
The apps like web browser or games are restricted from touching hardware directly for safety reasons, when an app needs to do something, it must ask the  OS for permission.
  - The Request : You click  "save" on a document.
  - The system call : The application sends a system call (an official API request) to the kernel.
  - The Translation : The kernel translates this request into  machine code that your storage device understands .
  - The Execution : The OS orders the drive to write the data, then reports back to the application that the task is complete .

### Juggling multiple task (context switching) 
A computer processor (CPU) can technically only  executes one calculation at a single micro-instant. To let you listen music, browse tabs and type simultaneously, the OS uses a trick called multitasking .
  - Time slicing : The OS scheduler cuts CPU time into tiny fractions of a second (milliseconds)
  - Swapping task : It gives application A  a fraction of a second, pauses it, saves it, exact state and handles the CPU to application B .
  - The illusion : This process, called context switching, happens thousand of times per second, making it look like everything is running at exact the same time.

### Hardware coordination (Device drivers) 
Every piece of a hardware speaks a slightly different technical language. The OS uses device drivers as translators .
  - When you plug in a new mouse, the OS loads its specific driver.
  - The driver converts your physical hand movements into universal coordinate data that the OS can pass along to any application.

### Safe Resource Guarding (Memory isolation) 
  - The OS draws invisible boundaries around the memory (RAM) allocates to each program .
  - If a faulty app tries to overwrite or peek into the memory space reserved for your banking app, the OS flags it as a violation, blocks the action, and crashes the faulty app safely without bringing down the whole system.
