# Role of Operating system 
The role of an operating system is to act as an intermediary between the user, application software, and computer hardware, serving two main purposes
  - Making the computer convenient to use.
  - managing resource efficiently.

## The Resource Manager
The OS acts as a manager that fairly distributes the computer's limited hardware resource among competing programs:
  - Processor allocation: Decides which app gets CPU time and for how long.
  - Memory tracking: Monitors every bite of RAM, tracking who is using it and reclaiming it when an app closes.
  - Storage allocation: Assigns space on hard drives or SSDs for saving files permanently.

## The Hardware Abstractor(The Universal Translator) 
Without an OS, software developers would have to write custom code for every  single model of hard drive, graphics card, and motherboard in existence.
  - Hiding complexity: The OS hides complex hardware detail from applications.
  - Standardise APIs: It provides a universal language (Application Program Interface or API) so that any app can print, display graphics, or save files regardless of the specific hardware brand.

## The Security Guard and Isolation Platform 
The OS protects the computer from malicious software, user errors, and system wide crashes :
  - Process isolation: Keeps application confined to their own memory bubbles so a crash in one app doesn't take down others.
  - Access Control: Enforces user permission, preventing standard accounts or rouge programs from modifying critical system files.
  - Data Privacy : Ensures one user cannot read or alter users private files .

## The Interface Provider 
The OS acts as the face of the machine, giving users a way to interact with the underlying electronics:
  - Graphical User Interface (GUI) : Provides visual elements like windows, icons, menus, and pointers for point and click control.
  - Command Lien Interface (CLI) : Provides a text-based environment where advanced users can type specific command directly to the system.
