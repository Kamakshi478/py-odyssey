# Classes 
  - A class is a blueprint or template used to create objects.
  - It is a foundational building block of object oriented programming.
  - It bundles data(attributes) and functionality(methods) together in a single, reusable pacakages.
  - Python is a object oriented programming language, it means almost everything from integers to strings is an object created from a class.

## What is inside a class?
A class groups two main things together to represent something in the real world:
  - Attributes(Variable/Data): What object knows or has.
  - Methods(Functions/Actions): What the object does or can perform.

Example: Car 
Component: The name of the blue print -> Car. 
Attributes: The characteristic or data -> colour, brand, top_speed.
Methods: The actions or behaviour -> start_engine(), accelerate(), brake().

## What does this look like in a code ?
  - Simple example of how class looks in Python.

        # 1. We define the blueprint (The Class)
         class Car:
                # A special setup function to assign details to each car
        def __init__(self, brand, color):
        self.brand = brand  # Attribute
        self.color = color  # Attribute

        # A behavior the car can do (Method)
         def honk(self):
            print(f"The {self.color} {self.brand} goes Beep Beep!")


          # 2. We use the blueprint to create real things (The Objects)
          car1 = Car("Toyota", "Red")
          car2 = Car("Ford", "Blue")

          # 3. We use the objects
          car1.honk()  # Outputs: The Red Toyota goes Beep Beep!
          car2.honk()  # Outputs: The Blue Ford goes Beep Beep!

## Why do we use class ?
  - Organization: Instead of having loose variables and functions floating everywhere, a class keeps everything that belong together in one neat box.
  - Reusability: Write the code for a car or a user account once, and you can instantly create millions of them without rewriting the logic.

## How to use class ?
  - Once a class blueprint is built, you can manufacture individual objects(also called as instance) from it.
  
         # Create objects (Instantiation)
         dog1 = Dog("Buddy", "Golden Retriever")
         dog2 = Dog("Max", "German Shepherd")

         # Access attributes using dot (.) notation
         print(dog1.name)   # Output: Buddy
         print(dog2.breed)  # Output: German Shepherd

         # Call methods
         print(dog1.bark()) # Output: Buddy says Woof!
         print(dog2.bark()) # Output: Max says Woof!

         # Access Class Attributes
         print(dog1.species) # Output: Canis lupus

## Core concepts 

### The class keyword 
  - You define a class using the class keyword followed by the name, which conventionally uses pascal case(capitalizing the first letter of each word).
### The constructor (_init_)
  - The _init_ method is a special magic method that runs automatically whenever you create a new object from the class.
  - Initialises the objects default state and attribute.
### The self parameter 
  - The self keyword represents the specific instance of the object you are currently creating or modifying.
  - It connects the variable and methods to that individual object.
  - You must include it as the first parameter of any instance method, though you don't pass it manually when calling the method.
