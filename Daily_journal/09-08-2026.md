# Bits in Python 
## Signed 32 bit integer
  - Is a whole number that uses exactly 32 bits(4 bytes) of computer memory to store its value.
  - Allows it to represent both positive and negative numbers
  - So the 32 bit integer allocates 1 bit to store the sign (positive or negative).
  - The rest of the 31 bits to store the values magnitude.
  - minimum value : -2^31 = -2147483648
  - maximum value : 2^31=2147483648
## How 32 bit integer is stored in memory ?
  - A 32 bit integer is stored in a memory as a sequence of 32 consecutive binary bits (4 bytes) using a system called two compliment to represent both positive and negative values.
### The bit structure 
The 32 bits are divided into two functional parts :
  - The sign bit (31 bit): The very first bit (most significant bit or MSB ) determines the sign.
  - 0 means the number is positive .
  - 1 means the number is negative.
  - The Magnitude Bits(bit 0-30): the remaining 31 bits represents the actual value of the number.
## The 32 Bit Memory slot 
  - Every 32 Bit integer occupies a fixed grid of 32 binary slots in memory.
  - Each slot holds either 1 or 0.
## Visualizing Three critical Integers 
### The Number 0
  - All slots are empty
  - Memory layout: 00000000  00000000  00000000  00000000
  - Everything is zero.
### The maximum positive integer(2147483647)
  - The signed bit is zero 0 (positive), and every other single slot is filled with a 1 .
  - memory layout: 01111111  11111111 11111111 11111111 .
### The minimum negative number (-2147483647)
  - Only the signed bit is filled with 1 , every other id filled with 0
  - Memory layout : 10000000  00000000  00000000 00000000
### The number negative one (-1)
  - every single slot in the 32 bit grid id filled with a 1 .
  - memory layout: 11111111  11111111 11111111 11111111
## Most significant bit 
  - The Most significant bit(MSB) is the left most binary digit in a binary number.
  - It holds the highest mathematical weight in the entire sequence.
  - changing it alters the overall numbers by a large amount by a large amount.
## Least significant bit 
  - Leftmost position in a standard binary string.
  - carries the lowest potential value .
  - Changing it only changes the total value by 1 or 0 (determines if the number is 1 or 0).
  - Determines even or odd status: an LSB of 0 means even, and 1 means odd .
