# Bits in Python 
## Signed 32 bit integer
  - Is a whole number that uses exactly 32 bits(4 bytes) of computer memory to store its value.
  - Allows it to represent both positive and negative numbers
  - So the 32 bit integer allocates 1 bit to store the sign (positive or negative).
  - The rest of the 31 bits to store the values magnitude.
  - minimum value : -2^31 = -2147483648
  - maximum value : 2^31=2147483648
## How 32 bit integer is stored in memory ?
  - A 32 bit integer is stored in a memory as a sequence of 32 consecutive binary bits (4 bytes) using a system called two compliment to represent both positive and negative values.
### The bit structure 
The 32 bits are divided into two functional parts :
  - The sign bit (31 bit): The very first bit (most significant bit or MSB ) determines the sign.
  - 0 means the number is positive .
  - 1 means the number is negative.
  - The Magnitude Bits(bit 0-30): the remaining 31 bits represents the actual value of the number.
## The 32 Bit Memory slot 
  - Every 32 Bit integer occupies a fixed grid of 32 binary slots in memory.
  - Each slot holds either 1 or 0.
