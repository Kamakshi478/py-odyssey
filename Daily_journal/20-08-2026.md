# Recursion
  - Recursion in Python is a programming technique where a function calls it self to solve a problem .
  - Instead of using a loop to repeat task, recursion breaks a large problem down into smaller, self similar sub problems until it reaches a point where it can stop.

## The Two Core Rules Of Recursion 
Every working recursive function must have two components to function properly without crashing:
  - Base Case: The stopping condition. when this condition is met, the function stops calling itself and returns a direct value.
  - Recursive case: The part of the function where it calls itself with  modified (usually smaller) arguments, moving closer to the base case.

## Performance Pitfall In Python 

### The Recursion Error (Stack overflow)
  - If you forget base case or pass the wrong arguments, you function will call itself infinitely.
  - To prevent your computer from crashing, Python sets a strict maximum recursion depth limit of 1000 calls.
  - If you exceed this, Python throws a recursion error.

### Lack Of Tail-call optimisation 
  - unlike some programming languages, Python does not optimize tail recursion. Even if the recursive call is the absolute last line of your function, Python will still build up a massive call stack in memory.

## How the call stack work behind the scenes
  - When python runs factorial(4), it stacks up the function calls in memory until it hits the base case, then calculates the value on the way back down:


         factorial(4) returns 4 * factorial(3)
         factorial(3) returns 3 * factorial(2)
         factorial(2) returns 2 * factorial(1)
         factorial(1) returns 1  <-- Base case reached! Now it unwinds:
         factorial(2) returns 2 * 1 = 2
         factorial(3) returns 3 * 2 = 6
         factorial(4) returns 4 * 6 = 24
