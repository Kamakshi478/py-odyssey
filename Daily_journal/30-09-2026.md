#  Closure functions and First class functions
  - first-class function means that the functions are treated like any other data type (like integers or string).
  - While closure are specific type of function that "remembers" the data from its surrounding environment even after that environment has finished running.
## First-Class Functions
  - A programming language has first-class functions if it allows functions to be treated as values. In Python, functions are objects. This means you can:
  - Assign them to variables
  - Pass them as arguments to other functions
  - Return them from other functions
  - Store them in data structures (like lists or dictionaries).

         def greet(name):
             return f"Hello, {name}!"

         # 1. Assigning to a variable
        say_hello = greet  
        print(say_hello("Alice"))  # Output: Hello, Alice!

        # 2. Passing as an argument to another function
        def display_message(func, value):
         return func(value)

        print(display_message(greet, "Bob"))  # Output: Hello, Bob!

## Closure Functions
  - A closure is a nested (inner) function that retains access to variables from its outer (enclosing) function's scope, even after the outer function has finished executing.
  -To create a closure in Python, three conditions must be met:
  - There must be a nested function (a function inside a function).
  - The inner function must reference a free variable (a variable belonging to the outer scope).
  - The outer function must return the inner function object itself.


         def multiplier(factor):
         # This is the outer function
        def multiply_by(number):
        # This is the inner function (the closure)
        # It remembers the 'factor' variable from the outer scope
        return number * factor
    
        return multiply_by  # Returns the inner function object

        # Create specific "factory" instances of the function
        double = multiplier(2)
        triple = multiplier(3)

        # The multiplier function has finished running, but 'double' and 'triple' 
        # still remember their respective 'factor' values!
        print(double(5))  # Output: 10
        print(triple(5))  # Output: 15

# Modifying Enclosing State (nonlocal)
  -If you want the closure to modify an immutable variable (like a number or string) from the outer scope, you must use the nonlocal keyword. Without it, Python will think you are trying to declare a brand-new local variable inside the inner function.


    def counter():
    count = 0  # Free variable
    
    def increment():
        nonlocal count  # Tells Python to use the outer scope's variable
        count += 1
        return count
        
    return increment

    my_counter = counter()
    print(my_counter())  # Output: 1
    print(my_counter())  # Output: 2


# Why Use Closures?
  - Data Hiding: They let you store and hide state without using global variables or creating a full object-oriented class.
  - Function Factories: They allow you to dynamically generate customized functions on the fly (like the multiplier example above).
  - Decorators: Python’s structural @decorator system relies entirely on first-class functions and closures to wrap and modify behavior.
