# Working with API's 
  - Working with REST APIs in Python typically relies on the requests library. It lets your Python scripts communicate with web services over HTTP to retrieve, create, update, and delete data
##  REST Basics
A REST (Representational State Transfer) API exposes data and actions through standard web URLs called endpoints (e.g., https://example.com). Communication happens through standard HTTP methods (often mapped to CRUD operations):
  - GET. Retrieves data from a resource without modifying it.
  - POST. Creates a new resource by sending a data payload.
  - PUT. Replaces an entire existing resource with new data.
  - PATCH. Partially updates specific fields of an existing resource.
  - DELETE. Removes a specific resource.
  - Most modern APIs exchange data using JSON (JavaScript Object Notation), which translates directly into Python dictionaries and lists.

## Setup and Making Requests
  - First, install the requests library via your terminal:

             pip install requests
  - Retrieving Data (GET)
    Use requests.get() to fetch data and pass URL query parameters cleanly via the params dictionary:

        import requests

        url = "https://typicode.com"
        params = {"userId": 1}

        response = requests.get(url, params=params)

        # Check status code and parse JSON
        if response.status_code == 200:
            data = response.json()  # Converts JSON response to Python list/dict
            print(data[0]["title"])

  - Sending Data (POST, PUT, DELETE)
    Use the json parameter when sending data. It automatically converts your Python dictionary to a JSON string and sets the Content-Type: application/json header:

 
        import requests

        url = "https://typicode.com"
        payload = {
            "title": "Python API Guide",
            "body": "Learning requests and REST.",
            "userId": 1
        }

        # Create a resource (POST)
        response = requests.post(url, json=payload)
        print(response.status_code)  # 201 Created
        print(response.json())

        # Update a resource (PUT)
        update_response = requests.put(f"{url}/1", json=payload)

        # Remove a resource (DELETE)
        delete_response = requests.delete(f"{url}/1")
