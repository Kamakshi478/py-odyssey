# Generator 
  - A Python Generator is a special kind of function that produces values one at a time instead of holding everything in memory at once.
  - Think of a normal function like a vending machine that dumps all its item on floor at once (return).
  - while a generator hands you one item , pause and waits until you ask for the next one.

## What is yield ?
  - The yield keyword is like a  pause button for a function .
  - Normal function (return): Gives a value  and shuts down completely. It forgets everything.
  - Generator function(yield): Gives a value, pauses and remembers where it  left off. when you ask for the next value, it wakes up and continues right after the yield line.

### Example of Yield 

    def count_upto_three():
    yield 1
    yield 2
    yield 3

    # Calling the generator creates a generator object
    my_gen = count_upto_three()

    print(next(my_gen))  # Output: 1 (pauses here)
    print(next(my_gen))  # Output: 2 (resumes and pauses here)
    print(next(my_gen))  # Output: 3 (resumes and pauses here)

## What is a Generator expression?
  - A generator expression is a quick, one-line shortcut to make without writing a full def function .
  - It looks almost identical to a list comprehension, but it uses parenthesis()  instead of square brackets[].
  - List comprehension( [ x for x in range (5) ]): Creates the entire list in your computer memory right now.
  - Generator expression((x for x in range(5))): Creates a lazy recipe that calculates the next number only when you ask for it.

### Example for a Generator expression

    # This does not create a list of numbers in memory; it creates a generator
    squares = (x * x for x in range(4))

    print(next(squares))  # Output: 0
    print(next(squares))  # Output: 1
    print(next(squares))  # Output: 4

## Why use Generators ?
  - Memory efficient: They use very little memory because they only keep one item in memory at any given second. this makes them great for huge files or massive data list.
  - Lazy evaluation: They don't do any work until you actually ask for the next value.
