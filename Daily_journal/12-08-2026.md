# LOOPS IN PYTHON 
 - Python uses two primary structures to execute a block of code repeatedly: for loop and while loop.
## For loop 
 - A for loop is like a automated checklist that tells python to repeat an action for every single item in a collection, one after the other, until it reaches the end .
### Basic iteration over a list 
 - The loop extracts each element one by one from start to finish.

        Fruits= [ "apple", "banana", "cherry"]

        for fruit in Fruits:

         print(fruit)

### Loop through a string 
  - Strings are Iterable sequence of individual characters.

        for letter in "Python":

        print(letter)

### Using the range() function 
 - When you  need to repeat an action a specific number of times, use range().
 - Single argument range(stop): Starts at 0 and ends before the specified number.
 - Two arguments range(start, stop): starts at start and ends before stop.
 - Three arguments range(start, stop, step): increments by the step value.
#### Iterates from 0 to 4
    for i in range(5):

      print(i)

#### Iterates from 5 to 9
    for i in range(5, 10):

    print(i)

#### Iterates from 10 down to 2, stepping by -2
    for i in range(10, 0, -2):

    print(i)
#### Looping over Dictionary 
 - Dictionary stores data in a key- value pair.
 - You can loop through them in three distinct ways:
## Iterating keys (default): for key in my-dict:

    my_dict= {"name":"Kamakshi", "age": 19, "city": "Bangalore"}

    for key in my_dict:

        print(key)
Output:

name

age

city

## Iterating values: for value in my_dict.values():
    my_dict= {"name":"Kamakshi", "age": 19, "city": "Bangalore"}

    for values in my_dict.values():

    print(values)
Output:

Kamakshi

19

Bangalore

## Iterating both keys and values: for key, value in my_dict.items():

    my_dict= {"name":"Kamakshi", "age": 19, "city": "Bangalore"}

    for key, value in my_dict.items():

        print(f"{key}: {value}")
Output:

name: Kamakshi

age: 19

city: Bangalore

# Advanced technique 
## Tracking indexes with enumerate()
 - Avoid using range(len(sequence)) to track list positions Instead , wrap the sequence in enumerate() to safely unpack both the index counter and the element value simultaneously.
 -      tech_stack = ["Python", "Django", "PostgreSQL", "Docker", "AWS"]

        for index, tech in enumerate(tech_stack):

        print(f"{index}: {tech}")
Output:

0: Python

1: Django

2: PostgreSQL

3: Docker

4: AWS

# Parallel iteration with zip()
 - To loop through two or more equal length lists at the same time, pair their elements using zip().

       name= ["Anna", "Bob", "Charlie", "David"]

       role= ["Manager", "Developer", "Designer", "Tester"]

       for name, role in zip(name, role):

          print(f"{name} is a {role}")

Output:

Anna is a Manager

Bob is a Developer

Charlie is a Designer

David is a Tester

# The else Block 
 - A for loop can have else block.
 - The code inside else executes only if the loop completes fully without running into a break statement.
 - This technique is highly effective for search operation.
