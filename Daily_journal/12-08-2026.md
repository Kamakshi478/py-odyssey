# LOOPS IN PYTHON 
 - Python uses two primary structures to execute a block of code repeatedly: for loop and while loop.
## For loop 
 - A for loop is like a automated checklist that tells python to repeat an action for every single item in a collection, one after the other, until it reaches the end .
### Basic iteration over a list 
 - The loop extracts each element one by one from start to finish.

Fruits= [ "apple", "banana", "cherry"]

for fruit in Fruits:

    print(fruit)

### Loop through a string 
  - Strings are iterable sequence of individual characters.

    for letter in "Python":

    print(letter)

### Using the range() function 
 - When you  need to repeat an action a specific number of times, use range().
 - Single argument range(stop): Starts at 0 and ends before the specified number.
 - Two arguments range(start, stop): starts at start and ends before stop.
 - Three arguments range(start, stop, step): increments by the step value.
#### Iterates from 0 to 4
for i in range(5):

    print(i)

#### Iterates from 5 to 9
for i in range(5, 10):

    print(i)

#### Iterates from 10 down to 2, stepping by -2
for i in range(10, 0, -2):

    print(i)
