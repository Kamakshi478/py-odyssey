# Class method 
Think of a python class as a factory blueprint, and instances as the actual items built by that factory.

  - A class method is a function inside a class that talks directly to the class blueprint itself, rather than a single object made from that blueprint.
  - When you call a class method, Python automatically passes the class as the very first argument.
  - By tradition, we name this argument cls (short for class). Because it has this link, a class method can see, modify or use things that belong to the entire class.
  - Main Job: It is most commonly used as an alternative constructor (a factory tool).If the standard way to create an object is too rigid, a class method can take different kind of data, clean it up, and then build an object for you .
  - Key sign: It always has the @ class method tag written above it , and its first input is always cls.

## Simple example 
Imagine a pizza blueprint. The standard way to make a pizza is by listing toppings. A class method lets you create a specific pre-set pizza, like a margherita, by talking directly to the blueprint.

    class Pizza:
    def __init__(self, toppings):
        self.toppings = toppings  # Standard way to make a pizza

    @classmethod
    def margherita(cls):
        # cls() here is the same as saying Pizza(["mozzarella", "tomatoes"])
        return cls(["mozzarella", "tomatoes"])

     # You don't need a pizza instance to use this; you call it on the class itself
    my_pizza = Pizza.margherita()
    print(my_pizza.toppings)  # Output: ['mozzarella', 'tomatoes']
