# Comprehensions In Python 
  - Comprehensions in python provide a concise, readable way to construct new data structures from existing iterables .
  - They effectively replace multi-line for loops and conditional filters with a single line of code .
## List Comprehension 
  - used to create a new list by transforming or filtering elements from an iterable.
  - syntax:

         [expression for item in iterable if condition]
  - Example : Get the squares of all even number from 1 to 5 .

        even_squares=[x**2 for x in range(1, 6) if x%2==0]
## Dictionary Comprehension 
  - Used to dynamically construct key-value pairs form an input iterable.
  - syntax:

         {key-expr :value_expr for items in iterable if condition}
  - Example- Store words as key and their length as values .

         words = ["apple", "pie"]
         word_lengths = {w: len(w) for w in words}
         print(word_lengths)

## Set Comprehension 
  - Similar to list comprehension, but it automatically  removes all duplicate values .
  - Syntax: {expression for item in iterable if condition}
  - Example: Extract unique vowel characters from a string

        text= "hello  world"
        vowels= {char for char in text if char in "aieou"}
        print(vowels)
##  Generator comprehension (Expression )
  - It is a memory-saving trick in python.
  - It looks almost identical to a list comprehension, but it uses parentheses() instead of square brackets.
  - Syntax: (expression for item in iterable if condition)
  - Example: generate a stream of of cubed numbers.

        cubes_gen = (x**3 for x in range(1, 1000000))
        print(next(cubes_gen)) 

## Difference between list comprehension and generator comprehension 
  - List comprehension [] makes the entire list all at once and loads it into your computers RAM .
  - Generator expression () makes item one at a time, only when you ask for them.
