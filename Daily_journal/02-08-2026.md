# Variables 
  - Variables are named containers used to store data value.
  - Variables are created at the moment you assign a value to them using the = operator.
# Rules for variables name 
  - Must start with a letter or an underscore .
  - Cannot start with a number.
  - can only contain alphanumeric character and underscore.
  - Are case sensitive.
  - Cannot be python reserved keywords like if, for or while.
# Data Types

# Python Keywords 
  - Python keywords are special, predefined words that are strictly reserved by the language to define its syntax and structure.
  - These words have specific meanings built directly into the Python interpreter.
  - we cannot use them as name for your variables, functions or classes.
# Major categories of Keywords 
## Value keywords 
  - True/False :The two fundamental states of Boolean logic.
  - None :Explicitly represents a blank state or the absolute absence of a value.
## Control flow & Iteration Keywords 
  - if/elif/else : Direct choices based on conditional logic blocks.
  - for/while : Creates loop through sequences of data.
  - break/continue : Interrupts or fast-forwards loops dynamically.
# Dictionaries in Python
  - A Python dictionary is an ordered collection of data stored as key value pairs 
  - Dictionary uses curly braces {}.
  - Each pair is separated by a colon : .
  - pair is separated by comma .
