# Variables 
  - Variables are named containers used to store data value.
  - Variables are created at the moment you assign a value to them using the = operator.
# Rules for variables name 
  - Must start with a letter or an underscore .
  - Cannot start with a number.
  - can only contain alphanumeric character and underscore.
  - Are case sensitive.
  - Cannot be python reserved keywords like if, for or while.
