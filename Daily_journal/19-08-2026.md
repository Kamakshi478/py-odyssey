# Functions

## Parameter 
  - A Parameter is a variable listed inside the parentheses of a function definition.
  - It acts as a placeholder to accept input data when the function is executed .

## Parameter vs Argument 
  - Parameter: The variable name written in the function definition.
  - Argument: The actual value sent to the function during a call.

         'name' is the PARAMETER (placeholder)
         def greet(name):
         print("Hello " + name)
 
         "Alice" is the ARGUMENT (the actual value)
          greet("Alice") 

## Main Types of Parameters in Python 
Python offers several ways to handle parameters for flexible coding.
  - Positional Parameters: Match based on their order.
  - Default parameters: Have pre-assigned value if left empty.
  - Arbitrary parameters(*args): Accept any number of positional inputs.
  - Keyword Arbitrary parameters(**kwargs): Accept any number instead of named inputs.

## Default parameter 
You can set a fall back value using the = operator 

    def welcome(user="Guest"):
    print("Welcome, " + user)

    welcome()         # Output: Welcome, Guest
    welcome("John")   # Output: Welcome, John

## Multiple parameters 
  - Functions can take multiple parameters separated by commas.

         def multiply(a, b):
         return a * b
 
         print(multiply(4, 5)) # Output: 20

## Argument 
  - An Argument is the actual  information you pass intp a function when you call it.
example :
Think of a function like a washing machine 
  - The machine has a slot for 'detergent' (this placeholder is called the parameter).
  - The actual liquid or powder you pour into the slot is the argument.

         # 'name' is the parameter (the empty slot)
        def say_hello(name):
        print("Hello, " + name)

        # "Alice" is the ARGUMENT (the real value we plug in)
        say_hello("Alice")

## Types of Arguments 

## Positional Arguments 
  - These are the most common arguments. They are matched strictly by their order(position). The first values goes to the first parameter, and second values goes to the second parameter.

        def describe_pet(animal, name):
        print(f"I have a {animal} named {name}.")

        # Order matters!
        describe_pet("dog", "Buddy")  # Output: I have a dog named Buddy.
        describe_pet("Buddy", "dog")  # Output: I have a Buddy named dog. (Wrong!)

## Keyword Arguments
  - You pass these by explicitly naming the parameter followed by the = sign. Because you name them, the order doesn't matter.

         def describe_pet(animal, name):
         print(f"I have a {animal} named {name}.")

         # Order doesn't matter here
         describe_pet(name="Buddy", animal="dog")  # Output: I have a dog named Buddy.

## Default arguments 
  - These are parameters that have a built-in fallback value. If you do not provide an arguments for them during the call, Python automatically uses the default.
  
        # 'animal' has a default value of "dog"
        def describe_pet(name, animal="dog"):
        print(f"I have a {animal} named {name}.")

        describe_pet("Buddy")          # Output: I have a dog named Buddy.
        describe_pet("Whiskers", "cat") # Output: I have a cat named Whiskers.

## Arbitrary Arguments 
Use these when you don't know beforehand how many inputs a user will pass.
  - *args (Arbitrary positional): Groups extra unnamed arguments in tuple.
  - **kwars(Arbitrary keyword): Groups extra named argument into a dictionary.

         # *args example for multiple inputs
        def list_food(*foods):
        print(foods)

        list_food("Pizza", "Burger", "Pasta") # Output: ('Pizza', 'Burger', 'Pasta')

## Return Value 
  - A return value is the final output that a function sends back to the main program after finishing its job.
Example:
Think of a function like a vending machine :
  - You put money in (input/argument)
  - The machine processes your request.
  - The machine gives you a snack (the return value).
    # This function calculates a number and RETURNS the answer

        def make_juice(fruit):
        return fruit + " juice"

        # We catch the return value and store it in a variable
        my_drink = make_juice("Apple")

        print(my_drink)  # Output: Apple juice


# Scope in Python 
  - Scope refers to the specific region of a program where a variable and can be accessed. If you try to call a variable outside of its scope, Python will throw a name error.
  - Python uses the LEGB rule to search for and resolve variable names.

## The LEGB Rule 
Python Looks for variables in a strict hierarchical order: 
  - Local scope : Variables created inside a function. They only exist while the function is running and cannot be accessed from the outside/.
  - Enclosing scope: Variables in the outer function of a nested setup (a function inside a function) .
  - Global scope: Variables created at the top level of the script, outside of any functions. They can be read from anywhere in the file.
  - Built-in Scope : Special keywords and functions predefined by Python (like print(), len(), or dict), Which are always available.
