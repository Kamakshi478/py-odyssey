# While Loop in Python 
  - A while in Python continuously executes a block of code as long as a condition evaluates to true .
## How it works 
  - Evaluates the condition: Python checks if the  condition statement is true or false .
  - Execute or skip: if it is false, the loop terminates immediately, and Python skips to the code below it. If it is true, Python runs the block of code inside.
  - Repeat: After executing the block, Python jumps back to step 1 to evaluate the condition again.
# The Three Pillars of a Safe while Loop 
  - To prevent code from running forever, a standard while loop relies on three essential parts:
### 1. Initialisation: Set up a starting variable
    temperature = 20

### 2. Condition: Define the boundary
    while temperature < 24:
       print(f"Current temp: {temperature}°C. Heating up...")
    
### 3. Modification: Update the variable inside the loop
         temperature += 1 

    print("Target temperature reached!")

##  Infinite Loop 
  - An infinite loop is a loop that never stops running because its condition is always True.
  - It will keep spinning forever and freeze your program until you manually force it to stop.

### Preventing Infinite Loop 
  - Most infinite loop happen by accident because you forgot to change the variable that the loop is checking.

#### The Broken code (Runs Forever)
    # The loop checks if count is less than 5. . 
    # But count stays 0 forever, so it never stops!
    count = 0
    while count < 5:
       print("Stuck in a loop!")
#### The Fixed code 
  - To fix it, you must change the variable inside the loop so the condition eventually becomes false.
  
          count = 0
          while count < 5:
                 print("Running...")
              count += 1  # This increases count, so it eventually reaches 5 and stops!

### Using Infinite Loop (on purpose)
  - To use infinite loop safely, you pair while True (runs forever) with a break statement(the emergency exit).

         while True:
           answer= input("Say 'Banana' to stop the loop: ")
           if answer == "Banana":
                 print("You found the exit world!")
                     break
           print("Wrong answer, try again!")
## Skipping Iteration with continue 
  - The continue keyword stops the current iteration right where it is and jumps straight back to the top of the loop to re-evaluate the condition .

        count=0 
        while count < 5:
               count +=1
                if count==2:
              continue 
             print(count)
## The Optional else block 
  - This blocks runs only if the loop completes normally (means the condition finally becomes False).
  - If the loop is terminated by a break statement, the else block is completely ignored.

          attempts = 0
          while attempts < 3:
              print("Trying to connect...")
              attempts += 1
          else:
          print("Connection failed after 3 attempts.")  # Runs because condition became False
