# File Handling 
  - File handling in python allows you to create, read, update and delete files directly through your code.
  - It is essential for saving data permanently as variables in your code disappear once your program stops running.
  - The industry standard for file handling is using the with statement, which automatically closes the file for you once you are done, preventing memory leaks or locked files.

## File opening Modes 
When you open a file, you must specify a mode:
  - 'r'(read): Opens a file for reading (Default). Throws an error if the file doesn't exist.
  - 'w'(write): opens a file for writing. Creates a new file or overwrites an existing one.
  - 'a'(append): Opens a file to add data to the end without deleting existing content.
  - 'b'(binary): Used for non-text files like images or pdfs .

## Common File Operation  

### Writing to a file 
  - Opening to a file with 'w' will create it if it does not exist. If it exists, it deletes everything inside and starts fresh.

         with open("example.txt", "w") as file:
         file.write("Hello, World!\n")
         file.write("This is a new line.")

### Appending to a File 
  - If you want to keep the existing text and just add more data to the bottom, use the 'a' mode .

         with open("example.txt", "a") as file:
        file.write("\nThis line is appended to the end.")

### Reading a File 
  - Python provides three main ways to read data depending on your needs:

#### Reads the entire file at once 

     with open("example.txt", "r") as file:
     content = file.read()
     print(content)

#### Read line by line (memory efficient for large files) 
 
     with open("example.txt", "r") as file:
        for line in file:
           print(line.strip())  # .strip() removes extra newlines

#### Reads all lines into Python list:

    with open("example.txt", "r") as file:
      lines = file.readlines()
       print(lines)  # Output: ['Hello, World!\n', 'This is a new line.']

## Advanced Operations 
  - For advanced file management like deleting files or checking if they exist, you can use Python's built-in os module .

         import os

        # Check if a file exists
        if os.path.exists("example.txt"):
         print("File found!")
    
         # Delete a file
         os.remove("example.txt")
        else:
         print("File does not exist.")
