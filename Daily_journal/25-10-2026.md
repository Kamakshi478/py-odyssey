# Performance Profiling 
  - Performance profiling is the process of measuring how long your code takes to run and finding out which parts are slowing down your program
  - Python gives you two built-in tools for this, and they serve very different purposes.
## timeit: The Stopwatch (For small snippets) 
  -  What it is: A tool used to time a tiny piece of code (like comparing two different ways to reverse a string or add items to a list).
  -  How it works: It runs your small snippet thousands (or millions) of times over and over, ignores background computer noise, and tells you the average speed.
  -  Analogy: It is like using a stopwatch to test whether running to the kitchen takes 5 seconds or 8 seconds.
  -  When to use it: You already suspect two specific lines or functions might perform differently, and you want to prove which one is faster.
## cProfile: The X-Ray / Full Audit (For whole programs)
  - What it is: A built-in profiler that looks at your entire program.
  - How it works: It tracks every single function your code calls, counts how many times each function ran, and records how much total time was spent inside each one.
  - Analogy: It is like an itemized store receipt that shows every single item you bought, the price of each, and where your money actually went.
  - When to use it: Your entire program feels slow, and you have no idea which function or file is causing the delay.
