# Standard Library Tour 
  - The Python Standard library is famously referred  to as "Batteries Included" meaning Python comes pre-packaged with a massive suite of robust modules to handle complex programming tasks right out of the box without needing to run pip install.

## System and File operation 
These modules bridge the gap between your python script and the host computers operating system.
  - os: Interacts with the operating system. Use to navigate Directories, read environment variables and manage file paths.
  - sys: Accesses system specific configuration parameters and variables. It handles command line arguments via sys.argv and system exist.
  - pathlib: Provides an object oriented approach to manipulating file system paths cleanly across Window, Mac and linux.
  - shutil: utility module designed for high level file operations like copying, moving and deleting entire directory trees .
  - glob: Uses pattern matching with wildcards (like *.text) to easily search for and list files in your system.

## Math, Numbers, & Randomization 
Python provides extensive support for basic and advanced calculations, precision, accounting and data simulation.
  - math: Provides underlying c-library mathematical functions for operations like trigonometry, logarithms and constants like pie.
  - random: Generates pseudo-random numbers, select random items from  array or shuffles data sets .
  - statistics: Built-in calculator for basic statistical matrices like mean, median, variance and standard deviation.
  - decimal: Essential for financial math. It avoids the floating-point rounding errors native to computers.

##  Advanced data structures & Text Processing 
When basics lists, dictionary, and string are not quite enough, these tools optimize your data handling.
  - collections: Provides specialized container alternatives to built-ins, such as counter (for tallying objects), deque (fast queues) and defaultdic.
  - itertools: core library for creating fast, memory-efficient loops and data iterators.
  - re: Powerful module for evaluating regular expression, which handles advanced string searching, manipulation and pattern matching.

## Date, Time & Serialization 
Managing time configuration and saving data structures across session natively streamlined.
  - datetime: Supplies classes for manipulating dates, time and timestamps while handling complex time zone modifications.
  - json: The industry standard module to parse JSON files or convert Python dictionaries into web-ready JSON strings.
  - csv: Directly reads and writes tabular to and from excel-friendly .csv files .

## Networking & Developer utilities 
Build small scripts to pull web data or test your own logic directly inside Python's runtime framework.
  - urllib.request : Native tool for fetching URLs and making basic internet data requests without third party dependencies.
  - argparse: Automatically generates clean, user-friendly command line interfaces (CLIs) with built in --help features.
  - Logging: Tracks application behaviour by creating diagnostic logs, replacing primitive print statement for production code.
