# Object Oriented Programming (OOP)
  - OOP in Python is a programming paradigm that organises code around objects and data rather than functions and logic alon.
  - It allows you to model real-world entities(like a new car, a user, or a bank account) by bundling their properties and actions together into self contained blocks.

## The Core Building Block 
To Understand OOP, you need to understand the relationship between a class and an object:
  - class: A blueprint or template used to create objects. It defines what data the object will hold and what it can do.
  - object: A specific instance created from the class blueprint. It holds actual data unique to that instance.
## The four pillars of OOP 
OOP is built in four core principles that makes software modular, flexible, and reusable.
  - Encapsulation: Bundling data and methods into a single unit and restricting direct access to shield internal data.
  - Inheritance: Allowing a class to adopt attributes and methods from an existing class to reuse the word.
  - Polymorphism: Many forms- allowing different classes to use the exact same method name but executes it differently.
  - Abstraction: Hiding complex backend logic and only exposing the essential user facing feature.

### Why to Use OOP in Python?
  - DRY (Don't repeat yourself): Inheritance lets you write code and reuse it across multiple parts of your application.
  - Easier maintenance: code is broken down into structured, isolated objects, making bugs easier to track down and fix.
  - scalability: It scales beautifully when transitioning from small scripts to large, complex software application.
