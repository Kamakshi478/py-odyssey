# Iterate  and Iterables 
  - In python , the difference between an iterable and an iterate comes down to stored state versus data capabilty.
  - while an iterable is the data collection itself.
  - An iterate is the agent that moves trough that collection step by step.
  - every iterate is also an iterable, but not every iterable is an iterate.

# Iterable
  - what it is - a  collection or a stream of data that can be looped over.
  - State- It is stateless , it does not know its current position in a loop.
  - memory- typically stores all elements in a a memory at once.
  - reusability- can be looped over multiple times (resets every time).
  - required methods- required _iter_() (or a legacy _getitem.())
  - Examples- list, str, tuple, dict, set, range().

# Iterate 
  - what it is - A stateful object that produces the next value upon request.
  - state- stateful. It remembers exactly where it is in the iteration.
  - memory- memory efficient, it only computes or fetches the next value when asked.
  - reusability- Exhaustible. Once you transverse it, it is empty and cannot be used.
  - Required method- required both _iter_() and _next_().
  - Examples- generator objects, file objects or objects returned by iter().

# How they work together ?
Python uses these two concepts under the hood to run every loop, list comprehension and unpacking operations.
  - iter(): when you pass an iterable to the built-in iter() funtion , it calls the object's _iter_().
  - next() : when you pass that iterator to the built in next()  function, it calls the iterator's next() method to get the next item.
  - StopIteration: When there are no items left, the iterator raises a stopiteration exception. A for loop catches this exception automatically to cleanly stop looping.
