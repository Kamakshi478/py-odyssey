# Operators 
  - Python operators are special symbols used to perform operations on variables and values.
  - They act as foundational building blocks for manipulating data, running calculations, and controlling programming logic.
## Arithmetic Operators
Used with numeric value to perform common mathematical calculations.
  - Addition (+)
  - Subtraction(-)
  - Multiplication (*)
  - Division (/)
  - Modulus (%)
  - Exponentiation (**)
  - Floor division (//)
## Assignment Operators 
Used to assign values to variable. They can combine Arithmetic operations with assignment as shortcuts.
  - Equals to (=)
  - Assignment after addition (+=)
  - Assignment after subtraction (-=)
  - Assignment after Multiplication (*=)
  - Assignment after division (/=)
  - Assignment after Modulus (%=)
  - Assignment after exponentiation (**=)
  - Assignment after Floor division (//=)
## Comparison Operators 
Used to compare two values. They always return a Boolean value either True or False.
  - Equals to (=)
  - Not equals to (!=)
  - Less than or equal to (<=)
  - greater than or equals to (>=)
  - Less than (<)
  - Greater than (>)
## Logical operators 
Used to combine conditional statements.
  - and: Returns True if both statements are true.
  - or: Returns True if at least one statement is true.
  - not: If an expression evaluates to True , applying not turns it into False. If it evaluates to  False it becomes True.
## Membership Operators 
Used to test if a sequence (like a string, list, or dictionary ) is present in an object.
  - in: True if the value is present in the data structure.
  - not in: True if the value is not present in the data structure.
## Identity Operators 
Used to check if two variables point to the exact same in computer memory. They do not check if the variables contain same value instead they check if the variables share the same memory address.
  - is: Returns True if both variables are the same object.
  - is not: Returns Trues if both variables are not the same object.
