# Built in methods 
## List methods 
  - append()- adds an item 
  - extend()- adds multiple item
  - insert()- adds at a specific position
  - remove()- removes an item
  - pop()- removes the item and returns it
  - clear()- removes everything
  - index()- finds position of an item
  - count()- count occurrences
  - sort()- sorts the list
  - reverse()- reverse the list
  - copy()- copy the list

## String method 
  - upper() - converts everything in uppercase
  - lower() - converts everything in lowercase
  - captialize()- first letter uppercase
  - title()- first letter of each word uppercase
  - strip()- removes spaces from beginning or end
  - lstrip()- removes space from left
  - rstrip()- removes space from right side
  - replace()- replace text
  - spilt()- converts strings to list
  - join()- joins list to string
  - find()- finds position
  - index()- finds position
  - count()- counts occurrences
  - startswith()- check  beginning
  - endswith()- check ending
  - isalpha()- only letters
  - isdigit()- only digits
  - isalnum()- letters/numbers?
  - isupper()- uppercase?
  - isspace()- spaces only?
