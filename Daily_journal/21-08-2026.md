# Modules in Python 
  - A module is a single file in python code(ending in .py). That wraps up variables, functions, and classes
  -  You can think of a module as a code blueprint or a lego brick that you can plug into other scripts to keep your project organized.

## Why we use modules ?
  - Reusability: Write code once in a module and use it across dozens of different files.
  - Maintainability: Breaking a massive script into smaller, specialized files makes bug easier to find.
  - Namespacing: Modules prevent naming conflicts. You can have a calculate(), function in module_a.py and another calculate() function in module_b.py without them crashing into each other.

## Anatomy of Module(An Example) 
  - Imagine you create a file named geometry.py . this file is now a module

         # geometry.py

         # 1. A variable (constant)
        PI = 3.14159

        # 2. A function
         def area_of_circle(radius):
        return PI * (radius ** 2)

        # 3. A class
        class Shape:
         def __init__(self, name):
        self.name = name
  - To use this module in a completely different file(eg- main.py). You can simply import it.

        # main.py
        import geometry

        # Accessing the module's contents using the dot (.) syntax
        print(geometry.PI) 
        print(geometry.area_of_circle(5))

## How Python Finds Modules 
When you type import geometry, Python doesn't look everywhere on your computer. It searches in a specific sequence called the Module Search path:
  - Current Directory: The folder where you currently running script is located .
  - PYTHONPATH: An environment variable containing list of directories (if set).
  - Standard Library Directories: The built-in folder where python's default tools(like math or os) live.
  - Site-Packages: The folder where third party libraries downloaded via pip are saved.
