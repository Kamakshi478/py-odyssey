# Modules in Python 
  - A module is a single file in python code(ending in .py). That wraps up variables, functions, and classes
  -  You can think of a module as a code blueprint or a lego brick that you can plug into other scripts to keep your project organized.

## Why we use modules ?
  - Reusability: Write code once in a module and use it across dozens of different files.
  - Maintainability: Breaking a massive script into smaller, specialized files makes bug easier to find.
  - Namespacing: Modules prevent naming conflicts. You can have a calculate(), function in module_a.py and another calculate() function in module_b.py without them crashing into each other.

## Anatomy of Module(An Example) 
  - Imagine you create a file named geometry.py . this file is now a module

         # geometry.py

         # 1. A variable (constant)
        PI = 3.14159

        # 2. A function
         def area_of_circle(radius):
        return PI * (radius ** 2)

        # 3. A class
        class Shape:
         def __init__(self, name):
        self.name = name
  - To use this module in a completely different file(eg- main.py). You can simply import it.

        # main.py
        import geometry

        # Accessing the module's contents using the dot (.) syntax
        print(geometry.PI) 
        print(geometry.area_of_circle(5))

## How Python Finds Modules 
When you type import geometry, Python doesn't look everywhere on your computer. It searches in a specific sequence called the Module Search path:
  - Current Directory: The folder where you currently running script is located .
  - PYTHONPATH: An environment variable containing list of directories (if set).
  - Standard Library Directories: The built-in folder where python's default tools(like math or os) live.
  - Site-Packages: The folder where third party libraries downloaded via pip are saved.

# Import 
  - In Python, the import keyword is the doorway that leds one Python file access code from another file.
  - When you import something, you are pulling variables, functions or claases from an external module into your from external  module into your current workspace so you can use them.

## How the import syntax works 
  - There are three main ways to use the import statement, depending on how clean you want your code to look:

### Importing the entire module(import module) 
  - This brings in the whole file. You must use the module's name as a prefix (called "dot notation" ) to use its content.
  
         import math

         print(math.factorial(5))  # Must prefix with "math."
  - Best for: Clean code. Anyone reading your file knows exactly which module the function came from.

### Importing specific item(from module import item)
  - This grabs only  the specific function, class or variable you need. You can use it directly without any prefix.

        from math import factorial

        print(factorial(5))  # No prefix needed!

  - Best for: Keeping your code short and punchy when you only you need one or two specific tools.

### Importing with a nickname (import module as nickname) 
  - This renames the module locally. It is highly popular in data science and machine learning to save typing time.

         import numpy as np
        import pandas as pd

        # Now you use 'np' instead of 'numpy'
         array = np.array([1, 2, 3])

## What Actually happens when you type import ? 
When Python encounters an import my_module statement, it performs three hidden steps in order:
  - Searches: It searches for a file named  my_module.py in your folder and system paths(sys.py)
  - Compiles: It compiles the module into bytecode (creating a .pyc file in the _pycache_ folder) to make it load faster next time.
  - Executes: It runs the module file from the top to bottom . Any variables, Functions or classes created during this runs are stored in a special dictionary so your current script can access them .
