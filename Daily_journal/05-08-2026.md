# Conditionals
  - Allows your program to make decisions and execute different blocks of code based on whether a condition is true or false .
  - they control the flow of your script.
## The core Syntax 
  - Python relies entirely on colons : and indentation (4 spaces) to define which lines of code belong inside a condition block.
## Handling Multiple choices 
  - If you have more than two possible outcomes, use elif to check additional conditions in order.
  - Python stops checking as soon as it finds the true condition.
## Comparison Operators 
  - Conditionals depend on comparison operator to evaluate choices, which always output a Boolean value (true or false )
### == equals to 
### != not equals to 
### > greater than 
### < less than 
### >= Greater than or equals to  
### <= Less than or equals to 

## Logical Operator 
  - You can combine multiple conditions into a single statement using logical operators
### and : Returns True only if both conditions are True.
### or : Returns True if at least one condition is true.
### not : Inverts the results (turns true to false, and vice versa).

## Inline conditional (Ternary Operator)
  - Single line decision, you can write an if-else  statements inside a single line to assign variable quickly.
