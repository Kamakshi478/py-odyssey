# Conditionals
  - Allows your program to make decisions and execute different blocks of code based on whether a condition is true or false .
  - they control the flow of your script.
## The core Syntax 
  - Python relies entirely on colons : and indentation (4 spaces) to define which lines of code belong inside a condition block.
## Handling Multiple choices 
  - If you have more than two possible outcomes, use elif to check additional conditions in order.
  - Python stops checking as soon as it finds the true condition.
## Comparison Operators 
  - Conditionals depend on comparison operator to evaluate choices, which always output a Boolean value (true or false )
###  == equals to 
###  != not equals to 
###  > greater than 
###  < less than 
###  >= Greater than or equals to  
###  <= Less than or equals to 


## Logical Operator 
  - You can combine multiple conditions into a single statement using logical operators
### and : Returns True only if both conditions are True.
### or : Returns True if at least one condition is true.
### not : Inverts the results (turns true to false, and vice versa).


## Inline conditional (Ternary Operator)
  - Single line decision, you can write an if-else  statements inside a single line to assign variable quickly.

# Loops 
  - Allows to execute a block of code repeatedly
python provides two main types of loops.
  - for loop (for iterating over a sequence).
  - while loop (for repeating as long as a condition is true).
## The for loop 
  - A for loop is  used to step through items in a sequence, such as list, tuple or string.
### Using the range() function 
  - To repeat a loop a specific number of times, use range(start, stop, step)
  - The stop value is not included.
## The while loop 
  - A while loop runs continually as long as a specified condition remains True.
## Loop Control statements
You can alter the flow of a loop using three special keywords:
  - break: Instantly terminates the loop completely.
  - continue: Skips the rest of the current iteration and jumps straight to the next cycle.
  - pass: A null statement used as a placeholder when syntactic code is required but you  want nothing to happen.
## Loop with an else block 
  - Python loops have a unique feature: an optional else block. The else code executes only if the loop finishes naturally (without encountering a break statement)
