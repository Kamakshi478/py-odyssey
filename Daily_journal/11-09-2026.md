# Inheritance 
  - Inheritance allows you to create a new class that reuses, modifies, and extends the behaviour of existing class.

## Base Class vs Derived class 
  - Base class(Parent/ superclass): The original class that contains the core properties(attributes) and behaviours(method).
  - Derived class(child/subclass): The new class that inherits everything from the base class. You can add new features to it or override existing one.

## A simple example 
  - Imagine a generic vehicle (Base class). A Car (derived class) is a specific type of vehicle. It inherits the ability  to move, but add its own specific features like a trunk or a numbers of doors.

## Code 

    # Base Class (Parent)
    class Vehicle:
        def __init__(self, brand):
          self.brand = brand

    def start_engine(self):
        return f"The {self.brand} engine is now running."

     # Derived Class (Child)
     class Car(Vehicle):
       def open_trunk(self):
         return "Trunk is open."
  - Because Car inherits from vehicle(Indicated by putting Vehicle in parentheses ), a car object can use both its own methods and the parents methods:

         my_car = Car("Toyota")

         print(my_car.start_engine())  # Output: The Toyota engine is now running. (Inherited)
         print(my_car.open_trunk())    # Output: Trunk is open. (Unique to Car)

## What is super() and why it is used ?
  - The super() function is a built-in Python tool that gives you access to the methods of the parent class.
  - It is most commonly used inside the the _init_ constructor.

  - When you create a derives class, it often needs to do two things during initialisation:
  - Runs the setup code of the parent class( So you don't repeat code).
  - Run its own unique setup code.
  - super() bridges that gap.

### Example code with super()

    # Parent Class
     class Employee:
         def __init__(self, name, salary):
          self.name = name
           self.salary = salary

       # Child Class
      class Manager(Employee):
      def __init__(self, name, salary, department):
        # super() links to Employee and runs its __init__ method
        super().__init__(name, salary) 
        
        # Now we handle the unique property for Manager
        self.department = department 

    def show_details(self):
        return f"{self.name} manages the {self.department} department."

  ### Why not just use the parent name ?
  - You could technically write Employee._init_(self, name , salary), but using super() is better because;
  - It maintains your code: If you change the name of the parent class from Employee to Staff, You only have to change it once in the class definition line, not everywhere inside your methods.
  - It Handles complex setups: If a class inherits from multiple parents(multiple inheritance), super() automatically figures out the correct order to call them.
