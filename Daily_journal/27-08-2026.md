# Debugging 
  - The process of tracking down, Analyzing, and fixing errors (bug) in your code.
  - while adding print() statement is a common starting point, Python offers professional,
    robust tools to pause your code, inspect variables and steps through execution line by line.

## The built in modern way: breakpoint()
  - Introduced in Python 3.7, the native breakout() function is the easiest way to drop into an interactive debugging session, you don't need to import anything.
 
        def calculate_discount(price, discount):
        final_price = price - (price * discount)
        breakpoint()  # 🔴 The code will pause right here
        return final_price

        calculate_discount(100, 0.2)
  - When you run this script in your terminal, the execution will pause at breakpoint(), and you will see a (pdb) prompt.

## Essential CLI Debugger commands (pdb) 
When your code pauses at a (pdb) prompt, you can type short commands to control and inspect your program:
   - p variable_name (print): Displays the current value of a variable.
   - n(Next) : Executes the current line and moves to the next line in the same function.
   - s(step): Steps inside a function call on the current line.
   - c(continue): Resumes normal program execution until it hits another breakpoint or finishes.
   - l(list): shows the 11 lines of source code surrounding your current postion.
   - q(quit): immediately stops the debugger and exits the program.
