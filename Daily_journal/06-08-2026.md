# PEP 8 
  - The official style guide for writing clean, readable and consistent python code.
  - PEP allows other developer to quickly understand your project.
## Naming convention 
The casing of your names indicate what kind of object they represent:
  - Variables and Function: Use lowercase words separated by underscore.
  - Classes: Capitalize the first letter of each word.
  - Constants: Use all upper case letters separated by underscore.
  - Modules: Use short, all lowercase names. Underscore can be used if it improves readability.
## Code layout and Whitespace 
  - Indentation: Use exactly space per indentation level. Never mix tabs and space.
  - Line length: Limit all lines of code to maximum of 79 characters.
  - Comment Length: Limits comments and docstring to 72 characters.
  - Blank lines: Surround top level functions and classes with two blank lines. Surround method definitions inside a class with single blank line.
  - Operators: Place one space before and after assignment(=), comparison(==), and Boolean operator.
