# Lists 
  - A Python list is a built in, ordered data structure used to store collection of items inside square bracket [] .
  - Lists are mutable (changeable) .
  - Allows duplicate value.
  - Can hold mixed data types simultaneously.
## Key Characteristic 
  - Ordered: Items maintain their specific insertion order .
  - zero indexed: The first element is accessed at index 0 .
  - Mutable: You can add, remove or modify items after creation.
  - Heterogeneous: Can store integers, strings, Boolean or even other list.


## Creation 

         Fruits= ["Apple", "Banana", "Cherry", "Date"]

## Accessing elements  
         print(Fruits[3])
         print(Fruits[1])
## Slicing 

     Fruits= ["Apple", "Banana", "Cherry", "Date"]
     print(Fruits[1:4])
## Modifying Items 

    Fruits= ["Apple", "Banana", "Cherry", "Date"]
    Fruits[1] = "Blueberry" 
    print(Fruits)
### Modifying multiple items at once

    Fruits= ["Apple", "Banana", "Cherry", "Date"]
    Fruits[1:3] = ["Blueberry", "Cranberry"]
    print(Fruits)

## Essential list Methods 
  - .append(item): Adds item to the very end of the list.
  - .insert(index, item): Inserts an item at specific index position.
  - .extend(iterable): Combines the list with another collection or iterable.
  - .remove(item): Deletes the first occurrence of a specific value.
  - .pop(index): Removes and returns the item at specified index (defaults to the last item) .
  - .clear(): Removes all elements, leaving the list completely empty.
  - .sort(): sorts the item in place(ascending order by default)

# Iteration in List 
  - Iteration in python lists is the process of accessing each element one by one using loops, comprehensions, or built in function.
  - The most common way to loop through a list is using a 'for' loop.
## Common way to iterate 
### Standard for loop 
  - Directly access each element in sequential order.

        Fruits= ["Apple", "Banana", "Cherry", "Date"]
        for fruits in Fruits:
        print(fruits)
### Loop with index(enumerate)
  - Access both the index number and the element simultaneously .

        Fruits= ["Apple", "Banana", "Cherry", "Date"]
        for index, fruits in enumerate(Fruits):
              print(f"{index}: {fruits}")
## List Comprehension 
  - Create a new list by iterating and applying logic inline.
