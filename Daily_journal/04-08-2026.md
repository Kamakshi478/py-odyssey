# Strings in Python 
  - A sequence of Unicode characters used to store  and manipulate text.
  - Defined under built in class 'str'.
# Key characteristic 
  - Zero Indexed: The first character is at index 0.
  - Negative indexing: Access Characters from the end of the string, starting at-1.
  - Immutable: - Strings are immutable, meaning tier contents cannot be changed after creation.
# Essential string method 
  - s.upper()- converts all characters to uppercase.
  - s.lower()- converts all characters to lowercase.
  - s.strip()- Removes leading and trailing space.
  - s.repalce("_","_")- Replaces a substring with another.
  - s.find()- returns the lowest index of substring.
# String slicing 
  - String slicing is how you grab a specific part of a string.
## The formula 
  - to slice a string, use square brackets [] and colons :
  - like this: string[start: stop: step].
  - start: The index where your slice begins (included).
  - stop: The index where your slice (not included ).
  - step(optional): How many steps to jump forward each time, Default is 1.
# How to use strings ?
## Glue them together (Concatenation)
  - you can use the + sign to combine the two pieces of text.
## Repeat them 
  - You can use the * sign to repeat a word multiple times.
# Formatted string (f-string)
  - The easiest way to insert variables directly inside a string in python.
  - You create an f-string by putting letter f or F directly in the front of your quotes, and then placing a variables inside curly brackets{}.
  - Example: print(f" My name is {name} and I am {age} years old")
# Key capabilities 
f-strings can do much more than just print variable names. Anything Inside the {} is treated like a live python code.
  - Do math inside the string: You can run calculations right inside the curly braces.
  - Run functions and methods: You can modify variables on the fly, like changing text to uppercase.
  - Formats numbers and decimals: You can control how numbers look, like rounding long decimals to two place using :.2f
  - Easy debugging trick: If u add an equal sign = after a variable name, Python prints both the name and its value
  
#  Input and Output 
The Input and Output are the core mechanisms that allow your program to interact with the outside world.

## Input 
  - Brings data into your program (usually from a user typing on a keyboard .
  - The input() function pauses your program and waits for the user to type something on their keyboard and press enter.
### The golden rule of input()
  - Everything that comes out of the input() function is saved as text (a string ). Even if the user types a number like 25, Python sees it as the text "25".
### Converting Input types (Typecasting) 
  - Input() only gives text, You must manually convert it to a number if you  want to perform mathematical equation.
  - use int() for whole numbers .
  - use float() for decimal .
### handling multiple Inputs at once 
  - If you want user to type multiple values on a single line (like two numbers separated by a space), combine input() with the .spilt() method.

# Comments 
  - A comment in python is text inside your code that the computer completely ignores.
  - Comments are written in plain human language to explain what the code does, making it easier for you or others to read and understand later.
## Single line comments 
  - The hash symbol # is used to create a single line comment.
  - Anything you type after # on that line will be ignored by python.
