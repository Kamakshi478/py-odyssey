# ASYNC Programming 
  - Asynchronous programming in Python allows a single-threaded program to handle multiple tasks concurrently.
  - It is highly efficient for I/O-bound operations (like fetching data from APIs, querying databases, or reading files) because it lets the CPU perform other work instead of waiting idly for slow external responses.

## Core concepts 
  - The Event Loop: The central coordinator. It manages and distributes the execution of different tasks. It tracks what is paused and switches execution to another task that is ready.
  - Special functions defined using async def. Simply calling them does not run them; it returns a coroutine object that must be explicitly scheduled or awaited.
  - The await Keyword: Pauses the execution of the coroutine, giving control back to the event loop until the result is ready. It can only be used inside async def functions.

## Code :Running Tasks Concurrently 

    import asyncio
    import time

    # 1. Define an asynchronous function (coroutine)
    async def fetch_data(task_id: int, delay: int):
       print(f"Task {task_id}: Starting...")
      # asyncio.sleep yields control back to the loop; time.sleep blocks it!
        await asyncio.sleep(delay) 
        print(f"Task {task_id}: Finished after {delay}s")
         return f"Result from {task_id}"

    # 2. Main orchestrator
    async def main():
    start_time = time.time()
    
    # TaskGroup automatically manages scheduling and errors
    async with asyncio.TaskGroup() as group:
        task1 = group.create_task(fetch_data(1, 3))
        task2 = group.create_task(fetch_data(2, 1))
        task3 = group.create_task(fetch_data(3, 2))
        
    # Execution pauses here until all tasks in the group finish
    print(f"All tasks completed in: {time.time() - start_time:.2f} seconds")
    print(f"Gathered: {task1.result()}, {task2.result()}, {task3.result()}")

    # 3. Entry point to kick off the event loop
    if __name__ == "__main__":
    asyncio.run(main())

     Task 2: Finished after 1s
     Task 3: Finished after 2s
     Task 1: Finished after 3s
     All tasks completed in: 3.00 second
     Gathered: Result from 1, Result from 2, Result from 3
### When NOT to Use Async 
  - PU-bound tasks: For heavy math calculations, machine learning, or image processing, async provides no benefit because the CPU is genuinely busy and cannot "yield" control. Use multiprocessing instead.
