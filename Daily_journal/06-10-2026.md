# Function tools 
  - functools stands for Function Tools. It is a built-in Python module filled with tools designed specifically to adjust, enhance, and manipulate how other functions behave.

## Why do we use it ?
- Instead of writing complex, repetitive code to modify a function, functools provides ready-made tools to handle common tasks:
- Performance Boosts: It can automatically make slow functions run instantly by remembering past calculations.
-  Reusability: It allows you to chop up large, complex functions into smaller, simpler, preconfigured versions.
-  Data Crunching: It helps loop through collections of data to distill them down to a single outcome.

##  reduce() — The Snowball Effect
  - reduce() takes a list of items and squeezes them down into a single final value by applying a function two items at a time, moving from left to right.
  - Real-Life Example: Tipping out a jar of loose coins and counting the total amount. You take the first coin, add it to the second, take that sum and add it to the third, and keep going until you hold one final total sum.

         from functools import reduce

         numbers = [1, 2, 3, 4, 5]
         # Adds: ((1 + 2) + 3) + 4) + 5
         total = reduce(lambda x, y: x + y, numbers)
         print(total)  # Output: 15

## lru_cache() — The Memory Box
  - lru_cache is a decorator that remembers the answers to expensive or slow function calls.
  - If you call the function again with the exact same inputs, it skips the heavy work and instantly hands back the saved answer. ("LRU" stands for Least Recently Used, meaning if it remembers too many things, it forgets the oldest ones you haven't asked for in a while).
  - Real-Life Example: Looking up a word definition in a dictionary. Instead of re-reading the entire internet every time someone asks for the meaning of "apple," you write it on a sticky note on your desk the first time you look it up. Next time, you just glance at the sticky note.

         from functools import lru_cache
         import time


        @lru_cache(maxsize=None)
        def slow_square(n):
         time.sleep(1)  # Simulates heavy work
         return n * n


         print(slow_square(4))  # Takes 1 second, computes it
         print(slow_square(4))  # Instant! Returns remembered result

## Partial 
  - partial is a tool in Python's functools module that lets you pre-fill or freeze some arguments of an existing function to create a brand-new, simpler function.
  - nstead of passing all the required inputs to a function every single time you call it, you use partial to lock in the inputs that rarely change, leaving you with a shortcut function that requires fewer arguments.


         from functools import partial


        # 1. The original, generic function
        def send_email(sender, receiver, subject, message):
         print(f"From: {sender} | To: {receiver}")
         print(f"Subject: {subject}\nMessage: {message}\n")


          # 2. Use partial to lock in the sender (since it's always you)
         # and the subject (since it's a specific newsletter)
         send_newsletter = partial(
         send_email, sender="news@mycompany.com", subject="Weekly Tech Update"
         )

        # 3. The new function only needs the receiver and the message!
        send_newsletter(receiver="alice@email.com", message="Here is this week's news!")
        send_newsletter(receiver="bob@email.com", message="Don't miss out on this issue!")

### Why to use ?
  - Cleaner Code: It eliminates repetitive arguments, keeping your main code loops short and readable.
  - Compatibility Fixer: Many Python libraries (like GUI frameworks or data processing pipelines) expect a function that takes exactly one argument. If your function requires three, you can use partial to freeze two of them so it fits perfectly.
