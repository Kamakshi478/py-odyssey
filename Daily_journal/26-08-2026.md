# Working with Data Formats (CSV & JSON)
  - Python features robust, built-in support for both CSV and JSON formats through its standard library.
  - You don't need to install any external packages to read, write or parse them.
  - While CSV is built for flat, tabular data (like spreadsheet).
  - JSON is optimized for hierarchical, nested structure (like nested dictionary).

## CSV 
  - CSV is just a plain text spreadsheet.
  - Instead of gridlines, it uses commas to separate columns and new lines to separate rows.
  - The built-in CSV module allows you to handle CVS data either as list or directly as python dictionaries.
  - Using dictionaries (DictReader and DictWriter ) is highly recommended because it maps the data directly to header names .

### The Example data 
Imagine you have a list of students:
  - Alice is 15 and gets an A .
  - Bob is 16 and gets a B.

How it looks in CSV file (students.csv)

     Name,Age,Grade
     Alice,15,A
     Bob,16,B

How to read in Python :
Python reads each line like a row in Excel.

     import csv

    with open('students.csv', mode='r') as file:
    # DictReader reads each row as a small dictionary
    reader = csv.DictReader(file)
    
    for row in reader:
        print(row['Name'], "is in grade", row['Grade'])

## Output:
 Alice is in grade A
 Bob is in grade B

## Reading a CSV file 

      import csv

     # Open the file safely using a context manager
    with open('data.csv', mode='r', encoding='utf-8') as file:
    # DictReader automatically treats the first row as headers
    reader = csv.DictReader(file)
    
    for row in reader:
        # Access elements by column name
        print(f"Name: {row['Name']}, Age: {row['Age']}")
## Writing a CSV file 
 
     import csv

    headers = ['Name', 'Age', 'City']
     data = [
    {'Name': 'Alice', 'Age': '30', 'City': 'New York'},
    {'Name': 'Bob', 'Age': '25', 'City': 'London'}
     ]

    # newline='' prevents blank lines between rows on certain operating systems
    with open('output.csv', mode='w', newline='', encoding='utf-8') as file:
    writer = csv.DictWriter(file, fieldnames=headers)
    
    # Write the header row first
    writer.writeheader()
    # Write all data rows
    writer.writerows(data)

# What is JSON ?
  - JSON is used when data is too complex for a simple spreadsheet.
  - It uses curly brackets {} for objects (like python dictionaries) and square brackets [] for lists.

## Working with JSON Data 
  - The Built-in json module translates JSON structures into native Python data types (like dictionaries and lists) and vice versa.
  - load/dump: Used for reading and writing directly to files .
  - loads/dumps: Used for JSON inside JSON inside strings (the s stands for string) .

### Reading and Parsing JSON 

    import json

    # 1. Parsing from a file
    with open('data.json', mode='r', encoding='utf-8') as file:
    data_from_file = json.load(file)

    # 2. Parsing from a JSON string variable
    json_string = '{"name": "Charlie", "skills": ["Python", "SQL"]}'
    data_from_string = json.loads(json_string)

    print(data_from_string['skills'])  # Outputs: ['Python', 'SQL']

### Writing and Formatting JSON 

    import json

    user_profile = {
    "name": "Diana",
    "active": True,
    "score": 94.5
    }
  
    # 1. Writing directly to a file (with 'indent' for human readability)
    with open('output.json', mode='w', encoding='utf-8') as file:
    json.dump(user_profile, file, indent=4)

    # 2. Converting a dictionary into a JSON string variable
    json_output_string = json.dumps(user_profile, indent=4)


# Exception in Python 
  - An Exception in Python is an error that happens while your program is running.
  - Even if your code has no typos and looks perfectly correct, an exception can occur if the computer encounters an unexpected situation- like trying to divide a number by zero, or trying to open a file that doesn't exist .
  - When an exception happens, Python  immediately stops running the program and display an error  message unless you tell it how to handle the situation .

## Common types Of Exceptions
Here are few common exception you will run into, explained simply:
  - ZeroDivisionError: You tried to divide a number by zero.
  - FileNotFoundError : You told Python to open a file, but that isn't there .
  - ValueError: You gave a function the right type of data, but an inappropriate value.
  -  TypeError: You tried to do something with mismatching data types.
  -  IndexError: You tried to look for an item in a list that doesn't exist.

## How to fix them : The try and except blocks 
To prevent your program from crashing, you can use a try and except safety net .
  - try: Put the risk code that might fail inside the block.
  - except: Put the backup plan here. This code only runs if something goes wrong .

### Handling a bad input (valueError)
Imagine asking a user for their age, but they typed the word "twenty" instead of a number.

    try:
    # This might fail if the user doesn't type digits
    age = int(input("Enter your age in numbers: "))
    print(f"Next year you will be {age + 1}!")

    except ValueError:
    # This only runs if the 'int()' function crashes
    print("Oops! That wasn't a valid number. Please use digits like 20.")

### Handling a Missing File (FileNotFoundError) 

    import json

    try:
        with open('config.json', 'r') as file:
          data = json.load(file)
        print("File loaded successfully!")

    except FileNotFoundError:
        print("Error: 'config.json' is missing. Loading default settings instead.")
        data = {"theme": "light", "volume": 50}

### The Full Structure : else and finally 
For advanced control, you can add two more optional box:
  - else: Runs only if the code in the try block succeeded without any errors.
  - finally: Runs no matter what, Whether an error happened or not. This is great for cleanup tasks (like closing an database connection) .

        try:
            result = 10 / int(input("Enter a number to divide 10 by: "))
            except ZeroDivisionError:
             print("You cannot divide by zero!")
         except ValueError:
             print("That was not a number!")
         else:
            print(f"Success! The answer is {result}")
         finally:
             print("Thank you for using the division program.")

# Raising exception in Python 
  - raising an exception means deliberately  triggering  an error in your code.
  - You use the raise keyword when a user or a system does something that is technically valid Python code, but breaks the logical rules of your specific program.
  - Python has no problem working with negative numbers.
  - If you are building an app that tracks a person's age or a bank account withdrawal, a negative number makes no logical sense.
  - You can raise  an error to stop the program before that bad data causes damage.

## How to use raise keyword
  - To raise an error, write keyword raise, choose the type of error that fits the best, and pass a helpful message inside parantheses ().

### Preventing Invalid Inputs 

    def set_age(age):

        raise ValueError("Age cannot be a negative number!")

     # Testing the function

## Re-raising an exception 
  - Sometimes, you want to catch an error using just to log it into a print warning, but you still want the program to crash or alert the main system. You can do this by using raise by itself inside the except box.

        try:
             with open("critical_data.csv", "r") as file:
             data = file.read()
        except FileNotFoundError:
             print("Log Alert: Someone tried to open a missing critical file!")
             raise  # This re-throws the FileNotFoundError so the system still fails safely
