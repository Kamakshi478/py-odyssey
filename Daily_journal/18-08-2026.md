# Functions 
  - Function is a reusable block of code that runs when it is called.
  - It helps to organise code into logical chunks, prevent repetition and make your program easier to read and maintain.

## Basic Syntax and Anatomy 
  - You define a function using def keyword, followed by the function name, parentheses (), and a colon :
  - The code inside must be indented.

         def greet_user():
        # This is the body of the function
         print("Hello! Welcome back.")
 
        # To run the code, you must call the function
        greet_user()  # Output: Hello! Welcome back.

## Passing Data (Parameters and Arguments) 
  - You can pass data into a function by putting a variable name inside the parentheses.
  - These are called parameters inside the function, and arguments when you pass the actual values.

        def greet_by_name(name):  # 'name' is a parameter
        print(f"Hello, {name}!")

        greet_by_name("Alice")  # "Alice" is the argument. Output: Hello, Alice!

## Returning Values 
  - Functions can send data back to the main program using the return statement.
  - Once a function hits a return statement, it exits immediately.
  
         def add_numbers(a, b):
         return a + b  # Sends the sum back

         result = add_numbers(5, 7)
         print(result)  # Output: 12

## Default Parameter Value
- You can assign default value to parameter, if someone calls the function without providing that  argument, Python will use the default value .

      def celebrate(name, occasion="Birthday"):
       print(f"Happy {occasion}, {name}!")

      celebrate("Sam")                     # Output: Happy Birthday, Sam!
      celebrate("Alex", "Graduation")      # Output: Happy Graduation, Alex!

## Handling flexible Arguments 
If you don't know beforehand how many arguments a user will pass, Python provide two special tools:
  - *args (Arbitrary Positional Arguments): Receives arguments as tuple.
  - **kwargs (Arbitrary keyword Arguments): Receives named arguments as a dictionary.

         # Using *args for multiple values

         def total_score(*scores):
        return sum(scores)

        print(total_score(10, 20, 30))  # Output: 60

         # Using **kwargs for multiple named values
        def user_profile(**info):
        print(info)
 
        user_profile(username="coder1", status="active")  # Output: {'username': 'coder1', 'status': 'active'}

## variable Space 
  - Variable created inside a function's local scope and cannot be accessed from the outside .

        def my_function():
        x = 10  # Local variable
        print(x)

        my_function()
        # print(x)  <-- This would throw a NameError because 'x' does not exist outside.
