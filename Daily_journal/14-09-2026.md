# Polymorphism 
  - Polymorphism is a core programming concept that allows different objects to respond to the exact same function or method name in their own unique way.
  - Polymorphism and method overriding work together to let different object use the exact same action name but handle it in their own unique way.
  - Polymorphism  literally means " many forms".
  - In programming it means you can treat completely different objects as if they were the same type because they share the same action names.

# What is Method Overriding ?
- Method overriding happens when a child class changes a tool or action it inherited from its parent class.
- The child  class keeps the exact same name for the action but completely replaces the instructions.
- The parent: Defines a general action.
- The child: Says " Thanks, but want to do this on my own way", and rewrites the behaviour .
