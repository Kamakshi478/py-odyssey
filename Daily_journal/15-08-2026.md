# Sets In Python 
  - A Set in Python is an unordered collection of unique elements.
  - Sets are commonly used to eliminate duplicate entries from data collection and to perform highly efficient membership testing (checking if an item exist).

## Key Characteristic 
  - No duplicates : Any duplicate items passed during creation are automatically ignored.
  - Unordered: Elements have no fixed sequence or index and may appear in a different order each time.
  - Unindexed: You cannot access elements using bracket syntax like my_set[0].
  - Hashable elements: While the set itself is a mutable (you  cannot add or remove element), the individual  items inside it  must be immutable data types like string, numbers or tuples .

## Basic set operation 
### Creating set 
  - You can create a set using curly braces {} or the set() constructor .

        Fruits= ["Apple", "Banana", "Cherry", "Date", "Elderberry"]
### Creating an empty set 

      empty_set = set()
### Adding or removing elements 

     # Add a single element
     fruits.add("orange")

     # Add multiple elements from another collection
     fruits.update(["mango", "grapes"])

    # Remove an element (Raises KeyError if not found)
    fruits.remove("banana")

    # Remove an element safely (Does nothing if not found)
     fruits.discard("watermelon")

##  Standard set- theoretic mathematical operation 
 Python provide both methods and operators to perform standard mathematical set operations .

  ###  Union
  - setA.union(setB)
  - setA|setB
  - All unique elements from both the sets
  ###  Intersection 
  - setA.intersection(setB)
  - setA & setB
  - common elements present in both sets.
  ### Difference 
  - setA.difference(setB)
  - setA-setB
  - elements in setA but not in setB.
  ### Symmetric difference 
  - setA.symmetric_difference(setB)
  - setA^setB
  - Elements in either set, but not in both.
