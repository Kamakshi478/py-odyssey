# Dunder Methods 
  - Dunder methods (short for "Double underscore"methods ) also known as magic methods.
  - These are special pre defined methods in Python that begin  and end with two underscore.
  - They are not meant to be called directly; instead the python interpreter invokes them automatically behind the scenes when a specific operations or built-in functions are executed on an object.
  - By defining dunder methods in custom classes, you unlock operator overloading and allows you custom object to integrate seamlessly with native python syntax, behaving just like built-in types (like integer, list or strings).

## Commom categories of Dunder methods 

### Initialisation and Construction 
  - _init_ (self,...) : The initializer method. It runs automatically when a  new instance of a class is created, setting up the initial state or attributes of the object.
  - _new_(cls,...): The actual constructor method that creates and returns the object instance .(Rarely overridden unless working with immutable types or metaclasses) .

### String Representation (Display)
  - _str_(self): Triggered by print(obj) or str(obj). It should return a human readable string format designed for end users.
  - _repr_ (self): Triggered bnny repr(obj) or when viewing objects in debugging environment /REPl. It should returnan unambitious, developer-facing string representation (ideally looking like a valid Python code to recreate the object).

### Arithemetic operators 
  - These allows you to define how your objects interact with standard mathematical operators:
  - _add_(self, other): implements the addition +  operator.
  - _sub_(self, other): implements the subtraction - operator.
  - _mul_(self, other): implements the multiplication * operator.
  - _truediv_(self, other): implements the true division /.

### Comparison operator 
  - These control how objects are ordered or evaluated against each other:
  - _eq_(self, other): Implements equality ==.
  - _lt_(self, other): Implements less than <.
  - _le_(self, other): Implements less than or equal to =<.
  - _gt_(self, other): implements greater than >.

### Container and Collection Emulation
  - These let your custom object mimic a list, dictionary or a set:
  - _len_(self): Invoked bu the len() function to return the size of the object.
  - _getitem_(self, key): Enables indexing or key lockup using square  brackets, like obje[key].
  - _contains_(self, item): Enables membership testing using the in operator (eg: item in obj).

### Code 

    class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    # Controls how the vector is printed for developers
    def __repr__(self):
        return f"Vector({self.x}, {self.y})"

    # Overloads the '+' operator
    def __add__(self, other):
        if isinstance(other, Vector):
            return Vector(self.x + other.x, self.y + other.y)
        return NotImplemented

    # Returns the absolute structural length of the vector coordinates
    def __len__(self):
        return 2

     # --- Testing the Magic Methods ---

    v1 = Vector(2, 4)
    v2 = Vector(1, 3)

    # 1. Triggers __repr__
      print(v1)  
    # Output: Vector(2, 4)

    # 2. Triggers __add__ behind the scenes: v1.__add__(v2)
    v3 = v1 + v2  
    print(v3)  
    # Output: Vector(3, 7)

    # 3. Triggers __len__
    print(len(v1))  
    # Output: 2
